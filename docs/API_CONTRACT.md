# API Contract Draft

These route names mirror the existing frontend client.

## Dashboard

- `GET /api/v1/dashboard/summary`
- Returns KPIs, weekly risk points, and severity mix for the command center.

## Findings

- `GET /api/v1/findings?status=pending`
- Returns procurement findings generated by the agent graph.

- `POST /api/v1/findings/{finding_id}/decide`
- Body: `{ "status": "approved" }` or `{ "status": "dismissed" }`
- Records a human-in-the-loop decision.

## Vendors

- `GET /api/v1/vendors`
- Returns vendor risk, transparent risk parts, exposure, and delay forecast.

## Documents

- `GET /api/v1/documents?recent=true`
- Returns the document queue and ingestion pipeline steps.

- `POST /api/v1/ingest`
- Multipart document upload.
- Queues guardrails, OCR/VLM extraction, chunking, indexing, and agent analysis.

## Operations

- `GET /api/v1/operations/health`
- Returns SLOs, latency, RAG metrics, trajectory evaluation, traces, and guardrail logs.
